|---|---|---|---|

## parser の境界と判定

- エラー結果 1 件につき組 1 件。通し番号、既知名か「その他の道具」、相対秒、対応の有無、次の呼び出し、次の同一道具呼び出し、既存と同じやり直し判定だけを返す。
- ID、元の独自名、本文、入力、結果は内部だけで照合する。時刻ソート済み events から隣の呼び出しを推測しない。
- 「直後の呼び出し」はエラー結果の後の最初の呼び出し。「次の同一道具」は失敗した呼び出しの後に行順で現れる同じ元名の呼び出し。異なる独自名を同一視しない。
- 複数エラーが次の呼び出しの前に並ぶ場合も、既存の集計と同じく最後のエラーだけをやり直し候補とする。対応が後から判明しても判定を遡って変えない。
- 時刻欠落は「時刻なし」、照合できなければ「対応不明」。エラー件数と組件数、やり直し件数と true の件数を試験する。

## 確認計画

既存試験を維持し、一覧の固定値・情報の非表示・行順・欠落・並列的な呼び出しの試験を追加する。1440 / 390 の両幅で見本 1・見本 2・壊れた行・長い許可モデル名を確認し、モデル欄を開いた状態でもページの横溢れがないことを検証する。計測の 7 事象と属性、通信 0 の監査は変更しない。指定の 3 画面、実行ログ、短い報告とコミットの format-patch を成果物として残す。
