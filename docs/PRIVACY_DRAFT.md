# Novus 導入後のプライバシー説明案

これは README の「解析サービスを使わない」という現在の説明を、Novus の計測導入後に書き換えるための案です。README 自体はまだ変更しません。現在の `measure-prep` はブラウザ内のイベントを出すだけで、外部へ計測情報を送りません。

## 掲載する文の案

会話の記録の読み込み・集計と PNG の作成は、これまでどおりブラウザの中で行います。記録の本文・ファイル名・作業フォルダ・ファイルの大きさ・行数・トークン数などの中身の数、道具名・モデル名は外部に送りません。本文・ファイル名・作業フォルダを画面や PNG に出さない仕組みも維持します。

作品を良くするために、Pendo の Novus で導入した計測を使い、ページの使われ方を計測します。たとえば、見本のボタンを押したか、自分のファイルを選択またはドロップしたか、読み込みができたか、時刻のある行があったか、図まで進んだか、PNG の書き出し処理が戻ったかを記録します。読み込めなかった理由や書き出しの失敗は、あらかじめ決めた札で記録し、例外の文章や記録の中身は送りません。

## 掲載前に実装と合わせる事項

実際の送信先、匿名の訪問識別の仕組み、Cookie 等の使用有無、保存期間、計測を止める方法についてはまだ決まっていません。Novus の PR を確認して事実が分かった時点で説明を補い、実装が上の約束を満たすことを確認してから README に反映します。自動収集により DOM の集計値、入力ファイルの情報、画面の複製などが送られないかも確認します。

上の案は、Novus の接続仕様や現在の利用人数を確認したという意味ではありません。計測する事象と送らない物の契約はルートの `HYPOTHESIS.md` を参照します。
